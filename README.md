## Projects
- **[Noise2Noise]([link](https://github.com/J-H3nry/Project_Noise2Noise))** ✅: an image denoiser trained using only noisy images, with no clean targets. Built for the Deep Learning course and inspired by the original Noise2Noise paper (linked in the repo). *Python, PyTorch*
- **[EasyTrace]([link](https://github.com/GKrafft2/easytrace))** ✅: autonomous navigation for a CrazyFlie quadcopter: fly through an obstacle field, find a landing platform, land on it, then return to the start. Built for the Aerial Robotics course, and our submission was later used as a demo for the following year's students. *Python*
- **GSL** 📦: a particle filter for gas source localisation, built with ROS 2. *C++* Coming soon, with the public repo and a full write-up.
